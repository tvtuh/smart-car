# 团队协作约定

1. 从 [README](../README.md) 和 [例程索引](examples.md) 确认改的是哪个独立工程。
2. 每个任务使用自己的分支，例如 `feature/encoder-calibration`。
3. 提交源码、必要的工程文件和说明；不提交 `out_file`、个人 IDE 状态、真实 Wi-Fi 信息。
4. 修改共享 `libraries` 时，在提交说明写明影响的例程，并重新编译相关工程。
5. 参数修改记录主板版本、轮径/编码器信息、测试环境与现象，避免把一台车的标定直接用于另一台。
6. 合并前说明三件事：改了什么、如何验证、哪些尚未上板测试。

建议任务状态使用“待办 → 进行中 → 待上板验证 → 已完成”，并单列“阻塞”，记录元件、PCB、设备和场地依赖。
